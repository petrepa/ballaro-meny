🔌 Bruk menyen

Hent Ballarò-menyen inn i din eigen app, og logg kva du et

← Tilbake til menyen
Heile menyen ligg som éi JSON-fil. Ho er open for alle, krev ingen nøkkel og kan hentast rett frå nettlesaren (CORS er ope). Same uoffisielle forbehald som elles: prisane i restauranten gjeld.

Adressa

https://petrepa.github.io/ballaro-meny/menu.json

Kom i gang

JavaScript 
const menu = await fetch("https://petrepa.github.io/ballaro-meny/menu.json")
  .then(r => r.json());

const pizzaer = menu.categories
  .flatMap(c => c.items)
  .filter(i => i.type === "pizza");
Python 
import json, urllib.request
url = "https://petrepa.github.io/ballaro-meny/menu.json"
menu = json.load(urllib.request.urlopen(url))
Terminal 
curl -s https://petrepa.github.io/ballaro-meny/menu.json \
  | jq -r '.categories[].items[] | "\(.name): \(.price) kr"'

Formatet

FeltKva
schemaVersjon av formatet. Blir auka berre om noko blir endra på ein måte som bryt eksisterande kode.
updatedDato menyen sist vart sjekka mot restauranten (YYYY-MM-DD).
restaurantNamn, adresse, phone (bruk i tel:-lenker), lenker til kart, Instagram og Wolt.
allergensKoder → namn, t.d. "HV": "Hvete/gluten".
categories[]id, name, tagline, items[].

Kvar rett (items[]):

idStabil ID, t.d. al-tartufo. Endrar seg ikkje om prisen gjer det. Lagre denne når du loggar.
nameNamnet slik det står på menyen.
descriptionIngrediensar (kan vere tom for drikke og ekstra).
typepizza, stromboli, lasagne, street-food, panuozzo, dessert, drikke eller extra.
priceLågaste pris i kroner (heiltal).
variantsValfritt. Storleikar eller antal: [{"id":"M","name":"Medium","price":256}, {"id":"L","name":"Stor","price":355}]. Cannoli har 1/2/4 stk.
allergensListe med koder, [] når menyen seier ingen, eller null når menyen ikkje oppgir det.
tagsValfritt: sterk, vegetar, vegansk, favoritt, signatur.

Logg kva du et

Prisar og meny endrar seg. Lagre derfor ein kopi av det du bestilte, ikkje berre ein peikar, så stemmer historikken din òg om eitt år: 
{
  "date": "2026-10-08",
  "items": [
    { "id": "al-tartufo", "name": "Al Tartufo",
      "variant": "L", "price": 355, "qty": 1,
      "rating": 5, "who": ["Peter"] },
    { "id": "tiramisu", "name": "Tiramisu",
      "price": 99, "qty": 1 }
  ],
  "note": "Trøffelen var på topp"
}
Med id kan du telje opp favorittar, sjå kva du ikkje har prøvd enno (menu.categories[].items[].id minus det du har logga), og rekne ut kor mykje du har brukt.

Hent gjerne fila når appen startar og hald på ein kopi, så verkar appen sjølv om GitHub er nede.

Idear

  • Ein «kva skal vi ha i kveld?»-terning som berre vel pizzaer du ikkje har prøvd.
  • Ei handleliste du ser på medan du ringer inn bestillinga.
  • Home Assistant: ein rest-sensor som hentar menyen, og ein knapp som loggar fredagspizzaen.
  • Allergenfilter for gjestar: skjul alt med N eller M.

Rett feil

Menyen er skriven av for hand frå papirmenyen. Ser du noko som er feil, eller har han endra seg? Opne ein issue eller send ein pull request som endrar menu.json.
